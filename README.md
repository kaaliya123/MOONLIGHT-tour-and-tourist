# Moonlight Tour & Tourist

A responsive one-page website for a Dehradun local tour / vehicle-rental business.

## Files
- `index.html` — website structure and content
- `style.css` — responsive design
- `script.js` — mobile navigation and year

## Netlify deployment
1. Create a GitHub repository.
2. Upload these three website files.
3. On Netlify, choose **Add new project → Import an existing project**.
4. Select the GitHub repository.
5. Build command: leave empty.
6. Publish directory: `/`
7. Deploy.

## Important photo note
The destination photos use real photographs from Wikimedia Commons and some general travel photographs from Unsplash. Before commercial publication, verify each image's license/attribution requirements.

The vehicle photos are representative real photographs, not necessarily the exact vehicles available for rent. Replace them with your own vehicle photographs when available; this will make the business site much more trustworthy.
